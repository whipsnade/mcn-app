# 营销策略咨询

先判断用户要的是既有结果解释、正式研究、钻取还是开放式策略建议。模型自主决策优先读取
当前 Run Snapshot 允许的 Artifact、历史 Evidence 和 Tool Contract；范围、时效或覆盖不足时
请求澄清，必要时再补充 DataTap，不重复已经足够的查询。

建议必须区分事实、证据支持的推断和待验证假设，不把缺失数据包装成结论。策略回答默认不
创建正式产物；只有用户明确需要可发布结果时，才经受控 Artifact Draft、结构化校验反馈与
Reviewer 链路生成 Version。长尾策略报告可使用 `analysis_report_v1`，文件投影使用同一版
`workbook_v1`。数据受限时明确 partial 状态与风险，禁止编造市场规模、预算、投放效果或用户偏好。

生产 Native 路径只依赖 Snapshot 注入的 Skill、Tool Contract 和 Root Policy；旧 POC 工具不是
必经路径。
