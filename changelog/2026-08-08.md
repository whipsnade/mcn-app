## Marketing Capability Pack B0：Task 3R canonical 契约语义修复

### 背景与目标

Task 3 测试虽通过但 Gate 未过，5 项 P1 语义缺陷：① 派生指标（如 Campaign
`overview.total_volume=1`）没有对应的最终 canonical field；② `field_lineage`
按 `(evidence_id, source_path)` 过宽映射，total_volume 会带上 engagement/
platform/post_id 等无关字段；③ canonical path 使用供应商原始别名（声量、
brand_mentions），同一业务语义因别名不同产生不同路径；④ CanonicalField 是普通
dataclass、availability 任意字符串、payload 用 `dict[str, Any]` 绕过验证；
⑤ 同一 Evidence 跨多个 group 被重复 canonicalize 产生冲突字段；⑥ Top posts
expected fields 不完整且缺失时伪造空串。本轮严格 TDD 修复，不进入 Task 4–7、
B1–B7 或方案 C。

### 主要改动（关键文件）

- 新增 `app/agent_artifacts/canonical.py`：强类型 `CanonicalField`（Pydantic，
  path 非空且以 `/data/` 开头、availability 仅 complete/partial/unavailable、
  unavailable ⟺ value=None、数值 complete/partial 必须有 evidence_ids、
  evidence_ids 去重）、`CanonicalPayloadMixin`（canonical path 不重复、
  field_lineage 键与 canonical path 集合完全一致且恒等映射到自身）、
  `publish_canonical`（从最终业务 data 走查全部叶子：value 与最终 payload 同
  一计算结果；evidence_ids 来自 LineageCollector refs 去重保序；availability
  按 value/partial_paths 推导；单位按路径末段推断）。
- `raw_rows.py`：改为两层结构的**内部 normalized source rows**（保留
  RowRef/extract_rows/别名/单位表），行级按 `(evidence_id, source_path)` 去重；
  删除 `_EXPECTED_GROUP_FIELDS` 与按 group+证据 id+原始 key 生成的旧 canonical
  fields/source_index/field_lineage；新增共享 `platform_coverage_incomplete`
  （scope 声明平台未被 Evidence 覆盖且无合计行时判定部分覆盖）。
- `builders/brand.py`/`campaign.py`：用 `publish_canonical(data, refs,
  partial_paths)` 发布 canonical_data + field_lineage；平台覆盖不全时
  overview 聚合字段 canonical 标 partial、章节标 partial、limitation
  `platform_coverage_incomplete`、data_status=restricted（有行才判定，无行
  仍 unavailable）。
- `builders/sections.py`：top_posts 的 title/author 缺失不再伪造 `""`（payload
  为 None）；platform/post_id/title/url/author/published_at 文本叶子也登记
  贡献行；likes/comments/shares/engagement 保持既有登记。
- `payloads/common.py`：`TopPost.title/author` 改为 `str | None`（Excel
  `present(None)` 显示「未采集」，前端 `post.title || '无标题'` 已兼容）。
- `payloads/brand.py`/`campaign.py`：继承 `CanonicalPayloadMixin`，删除
  `canonical_data: tuple[dict[str, Any], ...]` 宽松类型。
- `agent_runtime/evidence.py`：删除旧 dataclass `CanonicalField`，改为从
  `app.agent_artifacts.canonical` 再导出（normalization.py 的 re-export 不变）。
- `tests/agent_artifacts/test_marketing_canonical_sections.py`：按新契约重写为
  13 个测试，覆盖任务列出的全部 14 项语义（中英文别名同路径、跨平台求和、
  双 Evidence、精确 lineage、单帖 total_volume=1、显式 0、缺失 unavailable、
  部分平台 partial、跨 group 去重、五章节覆盖、top post 缺失 title/url、
