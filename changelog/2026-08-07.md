## Gate D/E Task 1 复审修复（2 P1 + 1 P2：字符串幂等键 / content_formats / 上传状态联合）

### 背景与目标

Codex 对 Task 1（前端 API、Artifact DTO 与事件状态契约）复审提出 3 个问题：
① 历史签名 `sendMessage(sessionId, content, idempotencyKey?: string)` 的字符串
第三参数被新 options 签名当作对象读取，Idempotency-Key 静默丢弃，破坏既有幂等
语义；② KOL scope 遗漏 `content_formats`（后端 KolSelectionScope 用于图文/视频
报价选择）；③ `ApiAgentUpload.status` 用宽泛 string，未收窄为后端实际三态。
严格 TDD 修复，不进入 Task 2，不做任何视觉/E2E/真实 UAT，不提交代码。

### 主要改动（关键文件）

**P1 字符串幂等键兼容**（`src/api/agent.ts`）
- `sendMessage` 改为 TypeScript overload 双签名（历史 `idempotencyKey?: string` 与
  新 `options?: AgentMessageOptions`），实现体统一接收 `AgentMessageOptions | string`
  并在入口确定性归一化：string → `{ idempotencyKey: value }`；object → 原样；
  undefined → `{}`。
- 行为不变：无第三参数 body 仍只有 `{content}`；options 正确发送
  parent_run_id/artifact_version_ids/upload_ids（空数组不进入 body）；
  options.idempotencyKey 正确发送 Header。

**P1 scope.content_formats**（`src/api/agentArtifacts.ts`）
- `KolSelectionPayload.scope` 增加可选 `content_formats?: string[]`（注释说明：
  新版本恒返回、历史版本可能缺失；不放进 filters/item）。

**P2 上传状态联合**（`src/api/agent.ts`）
- 新增 `export type AgentUploadStatus = 'uploaded' | 'parsed' | 'failed'`；
  `ApiAgentUpload.status` 由 `string` 收窄为 `AgentUploadStatus`（镜像后端
  UploadRead/数据库约束）。
