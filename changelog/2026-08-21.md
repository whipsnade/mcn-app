# 2026-08-21

## 背景与目标

重新划分正式 Pi Run、营销 Skill、可信执行内核和评测系统的职责。目标是让 Pi 自主处理品牌、
活动、达人及混合长尾需求，同时保留权限、计费、隔离、未知调用和不可变 Version 等安全边界；
生产 Skill 支持热更新，不再要求每次内容调整反复执行全量回归或离线 Corpus Replay。

## 主要改动

- 新增 `docs/superpowers/specs/2026-08-21-pi-autonomous-marketing-skills-design.md`。
- 确认生产使用 `noSkills: true + additionalSkillPaths=[run_snapshot_dir]`：关闭默认 Skill 发现，
  仅原生加载显式 Run Snapshot。
- 设计不可变 Skill Revision、全局/租户/百分比激活、运行中 Run 快照隔离和一键回滚。
- 标准 Artifact 继续保留；新增通用 `analysis_report_v1` 与同版 `workbook_v1` 投影，解除
  Top20、固定 Sheet 和单一 Artifact 等业务表达限制。
- 固化 Pi 澄清权、直接 MCP Tool Result、每个完成分析 Run 发布主报告以及失败降级语义。
- 将 candidate、Corpus、Stage 2A/2B、固定 observation 与多轮稳定性验证明确限定在评测域，
  不进入正式 Runtime 门禁。
