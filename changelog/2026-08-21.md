## Task 2：管理服务与 API

### 背景与目标

为管理员提供 Skill Revision 的校验、查看、数据库 Diff、激活、灰度和回滚入口，同时复用既有持久化幂等记录与审计日志。

### 主要改动

- 新增 `backend/app/marketing_skills/schemas.py`、`service.py`、`router.py`，挂载 `/api/v1/admin/skills`。
- 所有管理写操作都要求 `Idempotency-Key`；同 key 同请求回放安全 DTO，不同请求返回冲突；Revision 创建、激活和回滚均写 `admin_audit_logs`。
- 发布前只使用数据库审核工具目录和本地轻量校验，不调用模型、DataTap 或 Corpus；Diff 只读取数据库不可变 Revision 内容。
