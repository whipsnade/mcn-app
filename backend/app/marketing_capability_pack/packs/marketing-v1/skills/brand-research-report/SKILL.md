# 品牌社媒研究报告

确认品牌实体、日期窗口、平台、关键词和对比口径；决定性条件不足时请求澄清。按用户问题收集足以支撑章节的 Evidence，并检查字段口径、空值、时间范围与平台覆盖。

调用 build_brand_report_draft 时只提交 scope、Evidence ID 与允许的叙事字段。阅读 Builder feedback 的 availability、coverage、limitations 和 Evidence 引用后决定是否补查；不得手写报告 payload。发布后 Artifact Version、BI 与 Excel 必须一致；证据不足时透明说明 partial。
