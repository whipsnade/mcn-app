# KOL 评分 v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为新建 KOL 圈选任务实现严格缺失计零的八维评分、Top20 详情重算、正确 Excel 映射和全局评分说明。

**Architecture:** 新建纯评分投影模块，统一将会话画像、搜索字段与详情快照转为八个 0–100 原始分并计算 `kol_score_v2`。名单沉淀先生成初始分，Top20 详情保存后只重算该名单版本的对应项；旧名单保持原快照。澄清层在创建新 KOL 圈选任务前收集固定评分画像。

**Tech Stack:** FastAPI、SQLAlchemy Async、Pydantic、pytest、React 19、TypeScript、Vitest、openpyxl。
